 无名小服 · 群组状态

> 一个为 Minecraft 服务器打造的轻量级状态展示页面，单文件 HTML 实现，开箱即用。

---

## 📖 简介

这是无名小服的官方网站，用于向玩家展示服务器的实时状态与相关信息。页面采用单文件 HTML 编写，无需构建工具，部署到任意静态托管即可使用。

---

## ✨ 功能

- **服务器状态监控** — 实时展示在线状态、玩家数、延迟、版本、MOTD 与服务器图标
- **时间卡片** — 实时时钟、日期、按时段变化的问候语、每日一言
- **服务器地图** — 内嵌地图页面，支持懒加载与新标签页打开
- **公告系统** — 支持置顶、标签、日期排序
- **其他信息** — 分组展示友情链接、开发团队、赞助支持
- **国际化** — 内置中英文切换
- **深色模式** — 一键切换主题，偏好本地保存
- **离线缓存** — 网络异常时展示最近一次缓存内容
- **骨架屏** — 加载时展示占位骨架，提升感知性能
- **响应式布局** — 适配桌面与移动端
- **老设备兼容** — 自动降级视觉效果，保证功能可用

---

## 🎨 设计特点

页面采用**玻璃拟态**风格，配合柔和的弹性动画与渐变光影，营造轻盈、现代的视觉体验。整体色调以蓝色为主，可通过 CSS 变量轻松调整主题色。

动画节奏偏缓慢从容，卡片入场、视图切换、按钮反馈都带有轻微的弹性回弹，观感柔和不突兀。
